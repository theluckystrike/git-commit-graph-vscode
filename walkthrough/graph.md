# The commit graph

Run Commit Graph: Show Commit Graph, or click Graph in the status bar.

- Every branch, tag, remote branch and stash, each line in its own colour.
- Click a commit to see its message, parents and changed files. Click a file to open the VS Code diff.
- Ctrl+click (Cmd+click on macOS) a second commit to compare the two.
- The Branches button picks which branches to show. Remotes, Tags, Stashes and First parent turn parts on and off.
- Large repositories are fine: only the rows on screen are drawn, and the history is read in a background thread.
