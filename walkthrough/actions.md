# Actions that ask first

Right-click a commit, a branch label or a tag. Every action opens a confirmation that shows the exact git command, and nothing runs until you click the button.

- Check out a branch or a commit, create, rename and delete branches and tags.
- Merge, rebase, cherry-pick and revert.
- Reset soft, mixed or hard. Hard reset has a clear warning.
- Squash: click the newest commit, Shift+click the oldest, then Squash These Commits. The preview lists the commits and the git rebase todo list.
- When git stops (a conflict during a rebase or merge), a bar at the top offers Continue, Skip and Abort.
